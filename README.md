**▶️ เล่นเลย:** เปิดลิงก์ GitHub Pages ของ repo นี้ (Settings → Pages จะแสดงลิงก์)

- 9 มินิเกม: แข่งรถ ป๊อปลูกโป่ง บ้านผี หอคอยลาวา ร้านพิซซ่า ขุดอัญมณี และอื่น ๆ

- ฟักไข่สะสมมอนสเตอร์ 31 ตัว · แต่งห้อง · ปลูกผัก · ซีซั่นรายสัปดาห์

## สำหรับผู้ปกครอง
- ไม่เก็บข้อมูลส่วนตัว ไม่มีโฆษณา ไม่มีการซื้อด้วยเงินจริง ไม่มีแชท
- ความคืบหน้าเก็บในเบราว์เซอร์ของเครื่องที่เล่นเท่านั้น — กด **💾 สำรองข้อมูล** เพื่อเก็บรหัสไว้ใช้ย้ายเครื่อง
- แนะนำให้เล่นวันละไม่เกิน 20–30 นาที
